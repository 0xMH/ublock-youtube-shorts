# uBlock Origin: YouTube Shorts Blocker

A uBlock Origin filter list that hides all YouTube Shorts surfaces: shelves, cards, sidebar entries, tabs, and chips.

## Install

1. Open uBlock Origin dashboard.
2. Go to **Filter lists** → **Import**.
3. Paste the raw URL of `youtube-shorts.txt`:

```
https://raw.githubusercontent.com/mohamedhamza/ublock-youtube-shorts/main/youtube-shorts.txt
```

4. Click **Apply changes**.

## What it blocks

- Shorts shelves on the homepage and subscriptions feed
- Shorts cards in search results and related videos
- Shorts entries in the left sidebar (full and mini)
- Shorts tab in the bottom pivot bar
- Shorts chip in the filter bar
